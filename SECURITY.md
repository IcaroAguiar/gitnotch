# Relatar problemas de segurança

O projeto ainda não possui versão publicada ou implementação com suporte de segurança.

Não publique segredos, conteúdo privado de repositórios ou detalhes de uma vulnerabilidade explorável em issues públicas. Use o canal privado de reporte da plataforma se ele estiver habilitado no repositório.

O canal privado ainda não foi configurado nesta preparação. Se não houver canal disponível, solicite ao mantenedor um meio privado sem incluir os detalhes sensíveis. Nenhum endereço ou prazo de resposta é prometido neste documento.

Use uma reprodução sintética. Informe versão ou commit, sistema operacional, impacto e passos mínimos. Não envie credenciais reais.
