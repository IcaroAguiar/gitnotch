# Política de contribuições

Git Notch é um projeto pessoal disponibilizado publicamente sob a licença MIT. O desenvolvimento é conduzido pelo mantenedor com seus agentes.

Não estamos aceitando contribuições externas, PRs não solicitadas ou pedidos de implementação. O mantenedor não assume compromisso de revisar propostas ou oferecer suporte.

Você pode usar e adaptar o código conforme a [licença MIT](LICENSE), inclusive em seu próprio fork.
