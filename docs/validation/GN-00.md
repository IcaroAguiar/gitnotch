## Reproduza a avaliação

Execute na raiz do projeto:

```sh
git rev-parse --show-toplevel
git log --oneline --all
git diff --stat main...HEAD
git diff --check main...HEAD
git diff main -- git-notch-spec-v0.1.md git-notch-backlog-v0.1.md
shasum -a 256 git-notch-spec-v0.1.md git-notch-backlog-v0.1.md
git check-ignore .env .env.local node_modules/test dist/test target/test .DS_Store
git check-ignore pnpm-lock.yaml Cargo.lock .env.example
git status --short
git remote -v
```

A raiz deve ser esta pasta. O diff dos documentos originais deve estar vazio e os hashes devem coincidir com os valores acima. O primeiro check-ignore imprime todos os caminhos e retorna 0. O segundo não imprime caminhos e retorna 1, pois lockfiles e exemplo de ambiente podem ser versionados. O diff da branch contém apenas documentação e configuração do repositório. O status deve estar limpo depois do commit.
